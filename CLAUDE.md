# Simple Web Apps: project conventions

Collection of small HTML games and utility apps for desktop and phone browsers, hosted on
GitHub Pages (https://arnief3.github.io/simple_web_apps/).

## Structure
Every app is a top-level folder with the same layout:

```
<app-name>/
  index.html            the whole app: inline CSS + JS, no build step
  manifest.json         install metadata; start_url and scope are "./"
  icon.svg              source icon (512×512 viewBox, background = manifest theme_color)
  icon-192.png, icon-512.png, apple-touch-icon.png   generated by scripts/make_icons.py
```

- Keep each app in its single `index.html`. Extra files only for a compelling reason
  (large media → `<app>/assets/`; code shared by many apps).
- Every app is linked from the root `index.html` (`href="<app>/"`) and listed in the README table.
- Python (`uv`, pytest, Playwright) is only for tests and the icon script. No npm.
- `.nojekyll` makes GitHub Pages serve files as-is.
- Everything in the repo is public, so never commit secrets. An app that needs an API key
  must not ship it in the page.

## Every app must
- Have `<meta name="viewport" content="width=device-width,initial-scale=1">`, a `<title>`,
  and link `manifest.json`, `icon.svg` (`rel="icon"`) and `apple-touch-icon.png`.
  Games may add `maximum-scale=1,user-scalable=no`; utility apps keep zoom enabled.
- Work with mouse, touch and (where sensible) keyboard: use pointer events, not separate
  mouse/touch handlers; nothing that only works on hover.
- Fit phone screens: no horizontal scroll, use `dvh` instead of `vh` for full height,
  respect `env(safe-area-inset-*)`, tap targets ≥ 44px.
- Prefix every `localStorage` key with a short app-specific prefix (e.g. `qd_`, `mpd_`),
  and wrap storage access in try/catch.
- Work offline where possible: external resources (CDN scripts with pinned versions, fonts)
  are optional extras with fallbacks. Apps that depend on online services must fail with a
  clear message, use timeouts, retry transient errors and fall back to alternative services
  (see `miles-per-day` for the pattern).
- Support light/dark (`prefers-color-scheme`) for utility apps; games may use their own theme.

## Tests
- `tests/test_all_apps.py` checks every app automatically (desktop + phone viewport).
- Each app gets `tests/test_<app>.py` with interaction checks. External services are faked
  with `page.route` (responses need `Access-Control-Allow-Origin: *`).
- Run `uv run pytest` and `uv run ruff check tests scripts` after changes.
